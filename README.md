# projeto-multidisciplinar-backend
# 🌾 Rede Raízes do Nordeste - API de Back-End (MVP)

Este repositório contém a implementação do Back-End para o gerenciamento de pedidos e controle automatizado de estoque descentralizado da rede de franquias Raízes do Nordeste.

## 🛠️ Tecnologias Utilizadas
- **Runtime:** Node.js (Padrão ES Modules)
- **Framework:** Express.js
- **Banco de Dados:** SQLite (Configurado automaticamente em memória para facilitar a correção)

## 🚀 Como Executar o Projeto Localmente

1. Clone o repositório para sua máquina local.
2. No terminal da pasta do projeto, instale as dependências:
```bash
   npm install express sqlite3
